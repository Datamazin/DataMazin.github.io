Live AI Insight Demos

Both demos below run entirely in your browser: they pull live public data and an automated insight-generation engine writes the narrative — the same category of capability behind Microsoft Fabric Copilot and Fabric IQ. No server, no API key, nothing simulated.

Demo 1: Currency Risk Monitor

Live 30-day foreign-exchange data, analyzed for trend, volatility, and business risk.

1. Choose currencies to monitor (base: USD)

Demo 2: MLB Season Top Player Insights

Live current-season leaderboards from the official MLB Stats API, narrated automatically — the same pattern applied to sports data instead of finance data.

1. Choose stat categories to analyze

How these demos work

  • Live data: Demo 1 uses 30–35 days of exchange-rate history from the free, keyless Frankfurter API (European Central Bank reference rates). Demo 2 uses current-season leaderboards from the official, public MLB Stats API.
  • Automated analysis: trend, volatility, gaps between leaders, and cross-category standouts are all computed client-side, in JavaScript, right now.
  • Natural-language generation: a rule-based narrative engine turns those statistics into plain-English insight — no server, no API key, nothing to configure.
  • In a real engagement we'd extend this exact pattern using Microsoft Fabric Copilot or Azure OpenAI against your own sales, inventory, or financial data instead of public FX rates or box scores.

Demonstration only — not financial, investment, or fantasy-baseball advice.
